# The Hunter — prototype

Assistant de chasse aux bonnes affaires : The Hunter dit si une offre est une vraie bonne affaire, et pourquoi
(historique des prix, coût total, remises vérifiées, niveau de confiance).

**Prototype de démonstration non commercial.** Les produits, marchands et prix affichés sont **fictifs**.

Éditeur : The Hunter — projet de TimotheeNourris — contact : https://github.com/TimotheeNourris

Site statique (HTML, CSS, JavaScript), sans traceur ni cookie publicitaire.
